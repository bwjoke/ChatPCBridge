# Changelog

## 0.2.0 — First public source release

- Publish a clean, independently maintained Windows project under the ChatPCBridge name.
- Receive ZIP/TXT via Windows sharing, manual import or drag-and-drop; preserve original archives and prepare bounded text derivatives.
- Copy files and activate a configured ChatGPT destination, leaving final attachment verification and sending to the user.
- Keep one main window with temporary receivers, current-user IPC and live history refresh.
- Add reproducible Windows build/test automation, explicit local signing tools, security guidance and synthetic regression tests.

Earlier 0.1.x builds were private development prototypes. Their local diagnostics, certificates and chat data are not part of this repository or release history.
